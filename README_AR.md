# Alassal Smart Merchant – Complete Version

تطبيق تجريبي تفاعلي باستخدام Streamlit لإدارة وتحليل بيانات تجارة الجملة.

## تشغيل التطبيق محليًا

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud

1. ارفع الملفات التالية إلى مستودع GitHub:
   - `app.py`
   - `Alassal_Wholesale_Synthetic_Data.xlsx`
   - `requirements.txt`
   - `README_AR.md`
2. افتح https://share.streamlit.io وسجّل الدخول باستخدام GitHub.
3. اختر **Create app** ثم المستودع والفرع `main` وملف التشغيل `app.py`.
4. اختر اسمًا للرابط (مثل `alassal-smart-merchant`) ثم اضغط **Deploy**.
5. بعد اكتمال النشر انسخ رابط `*.streamlit.app` وشاركه مع صاحب المحل.

## صفحات التطبيق

- الرئيسية والملخص التنفيذي.
- ذكاء المخزون والصلاحية والتنبيهات بأسماء المنتجات والدفعات.
- التوصيات الذكية المبنية على قواعد تحليلية قابلة للتفسير.
- العروض وخصومات الكمية مع حد أدنى لهامش الربح.
- المبيعات والربحية.
- العملاء والتحصيل.
- الموردون والمرتجعات.

## ملاحظات قبل مشاركة الرابط

- ملف Excel المرفق يحتوي بيانات اصطناعية للتجربة، وليس سجلات فعلية للشركة.
- التطبيق لا يحتاج قاعدة بيانات خارجية في نسخة الديمو؛ يقرأ ملف Excel المرفق.
- محرك التوصيات الحالي Rule-based وليس نموذج تعلم آلي مدربًا.
- لا ترفع بيانات عملاء أو بيانات تجارية حقيقية إلى مستودع عام. إذا استُخدمت بيانات حقيقية، اجعل المستودع خاصًا وراجع صلاحيات الوصول قبل النشر.
- أي تغيير في ملفات GitHub سيؤدي إلى تحديث التطبيق المنشور تلقائيًا بعد إعادة النشر.
